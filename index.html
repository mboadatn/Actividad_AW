Document Object Model

Cada página web
es un árbol.

El DOM convierte tu HTML en una estructura de nodos que JavaScript puede leer, recorrer y modificar en tiempo real. Cada etiqueta es un element; cada relación entre etiquetas es una rama.

Esta es la misma estructura que tenemos en clase. Cada nodo tiene un padre, puede tener hermanos y puede tener hijos. Haz clic en cualquiera para ver cómo JavaScript lo describiría.

El objeto raíz

document

Todo empieza aquí. document representa la página completa y expone propiedades hacia el cuerpo y también hacia la cabecera.

propiedad

document.body

Devuelve el elemento <body> completo de la página.

propiedad

document.title

Devuelve el título de la página, el mismo que aparece en la pestaña del navegador.

propiedad

document.images

Un array donde cada índice es una imagen presente en la página.

propiedad

document.bgColor

Define el color de fondo: por nombre ("red") o en hexadecimal (#FFFFFF).

método

write() / writeln()

Escribe expresiones HTML directamente dentro del documento.

método

open() / close()

Abre o cierra el flujo de escritura del documento.

Encontrar nodos

Los tres métodos de acceso

01

getElementById()

Accede a un elemento por su id. No debe repetirse en todo el HTML. Es la forma más usada.

02

getElementsByTagName()

Devuelve un array con todos los elementos que coinciden con una etiqueta, en el orden del documento.

03

getElementsByName()

Recupera los elementos que comparten un atributo name, también en orden del documento.

Manejadores de eventos

Se agregan asignando una función a un evento: document.getElementById(id).evento = function() {}. Todos los demos de esta página funcionan así. 

document.getElementById("btnPulsame").onclick = function() {
  document.getElementById("demo").innerHTML = "Hola Mundo";
};
